## dashboard: `c` asks for the name, and forks a lane in one key

- **`c` asks what to call the window**, with an offer in the brackets:
  `name (the slug…): _ [repo-b-quail]`. The line starts empty, so typing your
  own name is typing it rather than backspacing over one; `enter` on an empty
  line takes what is in the brackets. The Name row on the form reopens the
  same prompt with the name it has now in the brackets, so `enter` keeps it.
- **The offer is the folder and one word** — `scripts-otter`, `repo-b-quail`
  — checked against every window and pending entry before it is offered. The
  second window in a folder used to be `scripts-2` and the third
  `scripts-3`; a digit tells you nothing about which of the three you are
  looking at, and a word can be said out loud. The same folder always offers
  the same word until that name is taken.
- **Two sub-window rows under `Create`**, whenever the cursor is on a live
  session: `empty, no prompt`, and `continues from its handover`, which
  pastes the brief `Schedule ➥resume` uses — read `STATUS-<parent>.md` and
  carry on from its *How to resume* section. Both make a `➥➥` child of that
  window, one `enter` each. The handover row is greyed with the reason until
  that lane has written one. `Create` still makes a top-level window.
- **A picker, a prompt or a confirm now goes where `Menu layout` says**, like
  the menu that opened it: centred on `modal`, under the cursor's panel on
  `table`, in the footer on `bottom`. Setting `modal` used to give a centred
  menu and then a footer panel for the answers it was collecting.
