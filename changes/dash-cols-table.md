## the engine for scrolling a table sideways, and Shift-←/→ as real keys

- **Nothing to see yet.** This is the arithmetic and the key reading that the
  sideways scroll and column pinning are built on; the sideways scroll, the
  pinning and the `Settings ▸ Columns` menu that turns them on arrive with the
  column menu, not here. No screen draws differently — the 153 golden screens
  are byte for byte identical.
- **Shift-← and Shift-→ are now keys the dashboard can tell apart** from a
  plain ← and →, which it could not before: both used to arrive as the plain
  arrow, so a key that scrolls a table sideways had nowhere to live. Nothing
  is bound to them yet. Every other modified arrow is unchanged on purpose —
  ctrl-←, alt-→, ctrl-shift-← and Shift-↑/↓ all still just move the cursor.
